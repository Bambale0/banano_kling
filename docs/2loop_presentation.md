# 2Loop — презентация проекта

## Слайд 1. Что такое 2Loop

**Заголовок**  
2Loop: AI-платформа и commerce-инфраструктура для Telegram

**Тезисы**
- Telegram-бот для генерации изображений и видео.
- Встроенные сценарии для фигурного катания, визуального контента и подбора аксессуаров.
- Платёжная система, реферальная логика, магазин и mini app в одном проекте.
- Проект уже работает как связка из бота, API-сервера, storefront и админского контура.

**Что показать на визуале**
- Премиальный Telegram-first продукт.
- Центральный экран бота.
- Вокруг: AI generation, payments, mini app, catalog, analytics.

## Слайд 2. Ключевые возможности

**Заголовок**  
Основной функционал

**Тезисы**
- Генерация изображений через Gemini / Nano Banana / Seedream.
- Генерация видео и motion control через Kling / Kie.ai / Replicate / Grok.
- Работа с референсами: до 14 изображений и до 5 видео в отдельных сценариях.
- Анализ фото в промпт.
- Пакетное редактирование изображений.
- Баланс GOE, платёжные провайдеры YooKassa и Robokassa.
- Партнёрская программа и реферальные бонусы.

**Что показать на визуале**
- Модульная схема из 6–8 карточек возможностей.
- Отдельные акценты на image AI, video AI, payments, storefront, partner system.

---

## Слайд 3. Архитектура

**Заголовок**  
Архитектура решения

**Тезисы**
- `aiogram` отвечает за Telegram UX и FSM-сценарии.
- `aiohttp` поднимает webhook/API сервер.
- SQLite хранит пользователей, транзакции, задачи генерации, аналитику и магазинные заказы.
- Есть отдельный storefront `/shop` и отдельный mini app API `/api/miniapp/*`.
- Статика и загрузки обслуживаются самим приложением.

**Что показать на визуале**
- Архитектурная диаграмма:
  Telegram -> bot handlers -> aiohttp server -> services/storage
- Отдельно вынести shop webapp и mini app API.

## Слайд 4. Пользовательские сценарии

**Заголовок**  
Как пользователь взаимодействует с системой

**Тезисы**
- Вход через `/start`, deep links, возврат после оплаты.
- Генерация фото: refs -> параметры -> промпт -> результат.
- Генерация видео: text/image/video flows и motion control.
- Фото -> промпт как отдельный бесплатный сценарий.
- Магазин: переход в каталог, проверка товара, промокод, оформление заказа.

**Что показать на визуале**
- Горизонтальный flow.
- Telegram mobile UI с короткими шагами.

## Слайд 5. Магазин и mini app

**Заголовок**  
Commerce-слой проекта

**Тезисы**
- Два магазинных контура:
  - storefront на `catalog.xlsx` + SQLite overrides;
  - React/Vite mini app с JSON storage.
- Каталог, карточки товаров, корзина и оформление заказа.
- Админское управление фото, остатками и ценами.
- Потенциал для объединения в единый source of truth.

**Что показать на визуале**
- Витрина товаров в мобильном Telegram mini app.
- Отдельная admin view с товарами, фото и стоком.
