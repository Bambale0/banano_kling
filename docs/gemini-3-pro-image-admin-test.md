# Gemini 3 Pro Image — админский тест OpenRouter

Путь: **Главное меню → 🧪 Тест → 🍌 Gemini 3 Pro Image · OpenRouter**.
Доступен только `config.is_admin()` в личном чате. Каждый callback и ввод в FSM
повторно проверяет права. В Mini App и публичном каталоге модель не добавляется.

## Как попробовать

1. Откройте «Промпт» и отправьте описание. Следующие сообщения дополняют текст;
   «Очистить» позволяет заменить его. Лимит тестового редактора — 20 000 символов.
2. Для редактирования/смешивания откройте «Референсы» и загрузите изображения,
   в том числе альбомом. Фото и файлы JPEG, PNG, WEBP до 20 МБ. Файлы сохраняют
   качество. Подпись к референсу дополняет промпт, если укладывается в лимит.
   Можно удалить последний референс или очистить все.
3. Выберите формат, разрешение, провайдера и время ожидания (120/240/480 секунд).
4. Нажмите «Создать». Результат приходит как превью и оригинал без сжатия.
   Если Telegram не принимает превью, отправляется оригинал.
5. «Получить результат» повторно отправляет сохранённые файлы без генерации.
   «Повторить запрос» запускает новый платный запрос с параметрами последнего
   успешного запуска. «Доработать» делает его первый результат референсом,
   очищает промпт и предлагает ввести правки. Это новая image-to-image генерация,
   а не чат с сохранением скрытого контекста модели.

Бананы не списываются, баланс и публичная лента не изменяются. OpenRouter
списывает средства с аккаунта владельца API-ключа. Фактический `usage.cost`
отображается, когда API его возвращает; стоимость не вычисляется по константам.

## Контракт и возможности

- Модель: `google/gemini-3-pro-image` (Nano Banana Pro).
- Авторизация: существующий `OPENROUTER_API_KEY`, Bearer на backend.
- Базовый URL: существующий `OPENROUTER_BASE_URL` (по умолчанию
  `https://openrouter.ai/api/v1`). Новых секретов и env-переменных нет.
- Возможности: `GET /images/models/google/gemini-3-pro-image/endpoints`.
  Кэш 5 минут; «Провайдер» и «Возможности» принудительно обновляют его.
- Генерация: `POST /images`, `model`, `prompt`, `n: 1`, `resolution`,
  необязательный `aspect_ratio`, `input_references` из `image_url` и
  `provider.only` только с провайдерами, поддерживающими всю комбинацию параметров.
  «Авто» для формата означает отсутствие `aspect_ratio` в запросе.
- Проверено 2026-10-03: Studio 1K/2K/4K, Vertex 1K/2K; до 14 референсов;
  форматы 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9.
  UI получает эти значения из API. При смене провайдера недоступное разрешение
  сбрасывается на его первое доступное; неподдерживаемый формат — на авто.
- Ответ: `data[].b64_json`, проверка base64 и реального формата изображения,
  `usage`, optional `id`. JSON ограничен 64 МиБ. Тело ошибки не попадает в UI/логи.
- Image API не заявляет для этой модели отдельные mask, seed, quality,
  transparency, web search или streaming. Такие поля не отправляются.
  Текст на картинке, свет, ракурс, локальные правки задаются промптом.

## Надёжность и хранение

Настройки, промпт, референсы, последняя попытка и последний успешный результат, их UUID/статус/метаданные
хранятся в существующей `bot_settings` под `gemini_image_lab:<admin_id>` с
`updated_by_telegram_id`. Миграции не нужны. Настройки переживают очистку FSM.
Изображения находятся в `outputs/admin-gemini-image/<uuid>/` существующего
Docker volume, вне публичного feed/static. Владелец сервера управляет сроком
хранения outputs; автоматической очистки этот модуль не добавляет. «Доработать»
копирует выбранный результат в штатное хранилище референсов для передачи провайдеру.

Nonce кнопки сохраняется/расходуется до POST. Мутации одного администратора,
включая параллельные фото альбома, сериализуются. Реализация рассчитана на текущий
одиночный backend runtime: перед масштабированием на несколько процессов нужен
распределённый lock/CAS. Таймаут конечен; автоматических повторов платного POST нет.

Результат сохраняется перед Telegram-доставкой. Неудачный повтор не удаляет доступ к предыдущему успешному результату. При сбое доставки используйте
«Получить результат». Работа выполняется в фоне, выход из меню её не отменяет.
После перезапуска незавершённый запрос становится «исход неизвестен» при открытии
экрана после истечения timeout + 60 секунд. Он не возобновляется автоматически;
перед новым запуском надо проверить OpenRouter Activity. Image API синхронный:
polling/webhook/task cancellation для этого endpoint не реализуются и не заявлены.

Логи `gemini_image_lab`: admin ID, внутренний UUID, модель/провайдер,
число референсов, разрешение, elapsed, provider ID (если присутствует), статус и
код ошибки провайдера/доставки. Не логируются промпты, ключи, референсные URL или base64.

проверка точного deployed SHA, health и post-deploy smoke. Откат — revert PR.
