# WAN 3.0 через Нейроныч — закрытая админская лаборатория

## Область действия

Кнопка **🧪 Тест → 🎬 WAN 3.0 · Нейроныч** в Telegram доступна только администраторам,
определяемым серверным `config.is_admin(telegram_id)`. Все callback и FSM-обработчики
повторно проверяют администратора. Обычные генерации WAN 3 / Prime, их тарифы,
повторы ленты и Mini App **не переключаются** на Нейроныча.

Поставщик использует уже существующую конфигурацию `NEIRONYCH_API_KEY`,
`NEIRONYCH_API_BASE_URL` и таймауты Neironych-клиента. Новые ключи не нужны.
GET `/v1/models` выполняется перед платным POST и должен содержать `wan-3`.
При недоступности каталога запуск блокируется.

## Режимы и ограничения

- Text: prompt, 2–30 секунд, 480p/720p/1080p, формат кадра
  (adaptive, 16:9, 9:16, 1:1, 4:3, 3:4, 21:9).
- Reference: до 10 изображений, 5 видео, 5 аудио, 20 материалов суммарно.
  Допускается аудиореференс без изображения. Входные видео и аудио — до 15 секунд в сумме отдельно по каждому типу; превышение отклоняется до POST.
  Видеореференсы вместе с заданной длительностью результата — не более 30 секунд.
- Frames: `start_image`, опционально `end_image`, без параллельных reference_*.
- Edit: первый `reference_video` — исходное видео; допускаются поддерживающие фото,
  видео и аудио. В native API **не передаются** `duration` и `aspect_ratio` (их
  определяет поставщик), присутствует `omni_reference_task_type=edit`.
- Seed: целое 0–4294967295 или Auto (поле не отправляется); генерация звука: true/false.

Формат отправки: `POST /v1/videos/generations` с `model=wan-3`,
`Idempotency-Key` и native полями на верхнем уровне. Это **не** KIE
`wan/3-0-video` и не `{model,input}`.

Референсы скачиваются только через Telegram API и сохраняются существующим
механизмом сервера с HTTPS URL; входные видео/аудио до 15 секунд. Если Telegram
не передал длительность видео/аудио (обычно при отправке как документа), файл
отклоняется до сохранения и платного POST с просьбой отправить его как медиа.
Отдельная админская лаборатория не вызывает пользовательские балансовые операции.
**Тестовые вызовы расходуют средства аккаунта Neironych**, поэтому запуск
выполняется только прямым нажатием администратора.

## Асинхронный результат и восстановление

POST не ретраится автоматически на сетевую ошибку: API мог принять задачу.
При неизвестном исходе в FSM отдельно сохраняются неизменяемые хэш конфигурации
и Idempotency-Key. Черновик можно редактировать, но новая отправка и сброс ID
блокируются, пока не восстановлена исходная конфигурация или поставщик не вернул
доказанный отказ HTTP 400/401/402/403/404/422 (для исключения второго платного задания).
Повтор запуска исходной конфигурации использует прежний ключ, без нового списания
при корректной idempotency на стороне провайдера. После получения `request_id`
запуск можно проверить `GET /v1/videos/{request_id}`; готовое видео скачивается
через авторизованный `/v1/videos/{request_id}/content` и отправляется админу
в Telegram как видео либо документ. При сбое доставки «Проверить» повторяет
**только доставку**, а не платную генерацию.

В логах допустимы admin_id, request_id, режим, хэш payload, типы ошибок;
полные тексты запросов, медиа URL и ключи не логируются.

Recovery-key хранится в FSM. В штатной production-конфигурации Redis переживает
рестарт процесса; если Redis недоступен и включился in-memory fallback, рестарт
может потерять ключ неизвестно принятого POST. В этом случае новый платный запуск
нельзя выполнять до ручной сверки с Нейронычем.

## Приёмка

1. Не-админ не видит кнопку и не может вызвать callback/FSM, POST не отправляется.
2. При отсутствии ключа или WAN3 в каталоге нет платного запроса.
3. Text/reference/frames/edit сериализуются в native-контракт без полей KIE.
4. Отправка POST с Idempotency-Key, polling, download и ручное восстановление.
5. Повтор ошибки после неопределённого POST использует прежний ключ.
6. Public WAN KIE, подписки, цены, персонализация повторов не изменены.
7. Проверены тесты и полный protected `tanyapi` CI; live paid smoke отдельно
   фиксируется фактом, а не предполагается.

Базовый reference backend: `Bambale0/ooo`, `app/contracts/registry.py`,
модель `wan-3` и примеры `app/api/native_video_reference.py` на 2026-11-01.
