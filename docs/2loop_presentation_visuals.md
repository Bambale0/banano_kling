# 2Loop — презентационные визуалы

Ниже собраны сгенерированные изображения для презентации проекта. Все файлы сохранены локально в `docs/presentation_assets/`.

## 1. Обложка

**Файл:** `docs/presentation_assets/2loop_cover.png`

**Назначение**
- Титульный слайд презентации.
- Позиционирование 2Loop как Telegram-first AI + commerce platform.
- Подходит для intro, инвестиционного deck-а, демо и внутренней презентации.

![2Loop Cover](presentation_assets/2loop_cover.png)

## 2. Возможности платформы

**Файл:** `docs/presentation_assets/2loop_capabilities.png`

**Что отражает**

- Референсы, фото -> промпт, платежи, магазин, аналитику и партнёрскую механику.

**Где использовать**
- Слайд с функционалом продукта.

## 3. Архитектура

**Файл:** `docs/presentation_assets/2loop_architecture.png`

**Что отражает**
- Telegram users.
- `aiogram` handlers.
- `aiohttp` server.
- Webhook layer.
- Storefront и Mini App API.
- SQLite / JSON / Excel storage.

**Где использовать**
- Техническая презентация.
- Архитектурный обзор проекта.
- Материалы для передачи разработки.

![2Loop Architecture](presentation_assets/2loop_architecture.png)

## 4. Магазин, Mini App и админский контур

**Файл:** `docs/presentation_assets/2loop_commerce_admin.png`

- Связку commerce + admin внутри одного продукта.

**Где использовать**
