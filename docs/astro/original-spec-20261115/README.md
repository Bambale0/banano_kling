## От спецификации к production

1. Эфемериды/историческая география и точное время: #559, #560.
2. Реальные AstroFacts каждого сервиса: #561–#567; отсутствующие данные явно помечаются.
3. Разделы/промпты из этих источников переносятся в **версионированную, админ-редактируемую** конфигурацию с полным coverage-check. Не подменять требования generic-планом из 8–12 кратких секций.
4. Только после подтверждённых расчётов — устойчивый LLM interpreter с source-facts evidence, очередью, checkpoint, idempotency и проверкой полного объёма: #568.
5. Согласие, приватность, история, безопасное владение данными, конфигурация тарифов и release gates: #569.
6. Функции остаются Telegram-admin-only, VK #451 исключён. Без approval тарифов **нет списаний**. Астрологическая интерпретация не заменяет научный прогноз, медицину и финансовую консультацию.

## Важное отличие от исследовательского #555

Черновик #555 описывает семь шаблонных планов, но у большинства значение min_total_words составляет 5400 и по 12 тематических секций. Это не эквивалент исходному объёму/охвату. #555 может быть фундаментом engine/checkpoint, но **не может закрыть** #568 или весь #544 без переноса всех обязательных разделов, проверки количества слов, фактической связности, конфигурации и производственного end-to-end.
