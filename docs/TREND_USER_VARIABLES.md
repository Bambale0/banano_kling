# Персонализация трендов (фото и видео)

## Контракт
- Зритель видит только названия полей, вводит собственные значения и загружает доступные референсы. Скрытый промпт, исходные значения и скрытые ассеты ему не выдаются.
- Сервер берёт полный авторский сценарий и применяет переменные. Сцена, свет, камера, действия, таймкоды и теги @ImageN/@VideoN/@AudioN сохраняются.
- В новом шаблоне автор может задать для каждого поля точное исходное значение (например, 37) из скрытого промпта. Пользователь вводит 2 — исходная цифра заменяется на 2 внутри авторского текста; для одной цифры отдельно уточняется, что нужна одна свеча или нарисованный знак. Даже если на фото-референсе старое число, в результате должно быть новое.
- Для ранее опубликованных трендов без разметки однозначные видимые числа (свечи, надпись, возраст) определяются автоматически. Отрицательные примеры, таймкоды, FPS и номера референсов не подменяются. Если значения неоднозначны, сервер не угадывает: сохраняет исходник и добавляет изменение в приоритетные параметры; админ должен указать точный исходный фрагмент при создании следующего шаблона.
- Нечисловые поля без привязки просто дополняют полный исходный текст, как в фото. Токены {{Поле}} поддерживаются для совместимости.
- Админская original_value хранится в приватной generation_settings, а публичный ответ user_fields исключает original_value. Секреты исходного промпта не выдаются в мини-приложение.
- Seedance 2.5 повторно использует подтверждённую серверную котировку при запуске, без повторного пересчёта цены и списания до подтверждения.
- Тесты проводятся на синтетических запросах, без обращений к платным провайдерам. Подстановка текста не гарантирует стопроцентную точность визуальных цифр у нейросети.
