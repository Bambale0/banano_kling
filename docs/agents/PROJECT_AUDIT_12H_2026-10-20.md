# NEUROMIX: аудит production за 12 часов и старых Docker-образов

Проверенное окно: **20 октября 2026, 11:14:50–23:14:50 МСК**
(08:14:50–20:14:50 UTC). Версия приложения при начале аудита:
`c9cf187497c1d9725424bf300b78a27a33e04e02`, ветка `tanyapi`.
Аудит выполнен только чтением. Образы, контейнеры, volumes, референсы,
uploads, outputs, пользовательские данные и резервные копии не удалялись.
Генерации, платежи, возвраты и повторные уведомления не запускались.

## Логи приложения: полные 12 часов

`logs/bot.log` покрывает обе границы окна. Форматтер приложения использует
UTC; nginx error-log использует Europe/London. PostgreSQL хранит эти
`created_at` как timestamp без timezone при серверном Europe/London, поэтому
границы SQL пересчитаны в **09:14:50–21:14:50** местного времени БД.

Обработано 227 172 событий: 226 152 INFO, 968 WARNING, **52 ERROR**, CRITICAL
не найдено. Это количество записей, а не число уникальных неудачных генераций.

| Группа ERROR | Записей | Оценка |
| --- | ---: | --- |
| Модерация провайдеров | 25 | sensitive/copyright/content-policy отказы; сами по себе не доказывают дефект приложения |
| Прочие ошибки генерации у провайдера | 5 | Две Internal Error, один timeout генерации, один timeout скачивания входа, один OSS NoSuchKey. Последний относится к upstream-ответу, а не доказывает удаление локального файла. |
| Обрыв upload-соединения | 11 | Девять Wan3 chunk и два Genjutsu upload, `ConnectionResetError` |
| Redis DELETE timeout | 3 | Сброс кеша saved refs; постоянное удаление файлов не выполняется этим методом |
| Анализ фото/видео/голоса | 4 | Пустой `prompt_ru`, не-JSON ответ модели, ошибки GPT при анализе видео и голоса |
| Wan 2.7: неподдерживаемый формат | 2 | Описаны выше |
| Пользователь заблокировал Telegram-бота | 2 | Ошибки отправки placeholder; не сбой генератора |

Дополнительно: 292 неаутентифицированных Lava webhook отклонены (185
`payment.failed`, 107 `payment.success`), две неверные подписи Prodamus
отклонены, 271 предупреждение rate limiter, два timeout соединения пула
PostgreSQL. Отклонённый success-webhook не является доказательством
незачисленной реальной оплаты: без сверки invoice такой вывод невозможен.

В клиентской телеметрии есть 62 upload-response HTTP 400, 744 успешных
JSON-fallback HTTP 200 и одна upload-network-error. Суммы не означают
соответствие один к одному: fallback не всегда имеет предшествующую
зарегистрированную multipart-попытку. Для Seedance 2.5 image: 51 отказ и
49 успешных fallback; для Seedance 2.5 video: пять и три. Исход остальных
попыток по этим агрегатам не подтверждён.

Три `react-error-boundary` события относятся к двум JS-чанкам. На момент
аудита оба возвращают HTTP 200; в сохранившемся access-log за окно для них
есть 731 HTTP 200 и один 499. Это не подтверждает отсутствие сетевых проблем
Telegram/WebView и не доказывает удаление чанков.

Текущий Docker-контейнер создан 19:56:17 UTC, поэтому его stdout не заменяет
файловый журнал всего окна. В его части окна: 7 514 строк, ERROR/CRITICAL нет.
Синтетический локальный тест не установлен как источник перечисленных
52 ERROR; результаты тестов не смешивались с количеством реальных задач.

## Задачи, платежи и ссылки на файлы

Все запросы к production PostgreSQL выполнены с
`default_transaction_read_only=on`, statement timeout и lock timeout.
Использован прямой psycopg без запуска runtime-миграций. Здесь указаны задачи
и счета, **созданные в окне**, со статусами на момент последующего чтения БД.

- Задачи: **1 492**, из них **1 408 completed**, **84 failed**.
- У всех completed есть result URL; 1 395 имеют `delivery_status=delivered`,
  13 — `unavailable`. Последнее не равно потере результата: Mini App и
  доставка в Telegram — разные поверхности.
- У 78 failed есть `refund_state=refunded`; шесть без этого маркера, из них
  три имеют нулевую стоимость, три платные описаны выше.
- Платежи: **98 completed, 208 pending, девять failed**. У Lava соответственно
  четыре, 14 и девять; остальные провайдеры: Freekassa, Robokassa, Stars, Tribute.
- Не найдено отрицательных пользовательских/партнёрских балансов, completed
  дублей `(provider, payment_id)`, задач/платежей/saved refs без пользователя
  или trend assets без шаблона. Это проверки текущего состояния, а не полное
  доказательство финансовой истории. Уникального provider/payment_id индекса
  в текущем PostgreSQL нет; миграция требует отдельного рассмотрения старых
  pending placeholders и не выполнялась.
- В snapshots входов этих 1 492 задач проверено **1 278 уникальных локальных
  файлов: все присутствуют**. Проверены `request_data`,
  `feed_repeat_reference_selection`, `feed_reference_selection`. Это не полный
  аудит всех исторических приватных и неудачных повторов.
- Все 47 216 saved refs и все 26 строк trend assets проверены через stat
  локальных путей; результаты и существующие пропуски приведены выше.
  В `user_prompts.generation_settings` нет документов с `/uploads/`; это не
  означает отсутствие референсов на других поверхностях.
- `bot-latest.tar.gz` текущей штатной процедуры содержит DB dump. Наличие
  этой копии не подтверждает отдельный backup `static/uploads` или успешный
  restore drill пользовательских медиа.

## Docker: что можно подготовить к удалению

На общем хосте: 99 образов, 17 связаны хотя бы с одним контейнером, 82 не
связаны. Docker показывает 94,17 GB образов и 81,31 GB reclaimable, но это
общая оценка всех проектов хоста. Build cache отдельно: 26,73 GB, из них
22,3 GB reclaimable. В этом аудите не удалялось ничего, включая build cache.

Ограниченные кандидаты NEUROMIX — **три образа**, оценка уникальных данных
образов примерно **5,23 GB** (около 4,87 GiB). Общий virtual size — 5,41 GB;
он не равен реально освобождаемому месту. BuildKit/shared layers могут
изменить фактический эффект удаления.

| Образ | ID | Создан | Virtual size | Unique size по Docker | Контейнеров |
| --- | --- | --- | ---: | ---: | ---: |
| `banano-genjutsu-check:37d2727` | `851d3714e61a` | 03.10.2026 | 2,27 GB | 2,273 GB | 0 |
| `banano-kling-runtime-reliability:test` | `c96d121087eb` | 12.09.2026 | 1,14 GB | 957,1 MB | 0 |
| `banano_kling:latest` | `f39b708c6851` | 07.08.2026 | 2,00 GB | 1,998 GB | 0 |

Для каждого кандидата проверены ссылки **всех** running/exited/created
контейнеров. Также прочитаны все семь слоёв каждого образа через поток
`docker image save`, без извлечения и без создания контейнеров: 28 200,
17 788 и 18 142 файловых записей соответственно. В слоях нет файлов под
`app/static/uploads/`, `app/outputs/`, `app/backups/` или `app/.env`; найденные
DB-заглушки имеют нулевой размер. Под `app/data/` в каждом образе всего
14–16 KB. Текущие compose, deploy scripts и systemd units не ссылаются на
эти три имени образов.

Production хранит реальные файлы на host bind mounts:

| Host path | Контейнер |
| --- | --- |
| `/root/tanya/banano_kling/static/uploads` | `/app/static/uploads` |
| `/root/tanya/banano_kling/data` | `/app/data` |
| `/root/tanya/banano_kling/outputs` | `/app/outputs` |
| `/root/tanya/banano_kling/backups` | `/app/backups` |
| `/root/tanya/banano_kling/logs` | `/app/logs` |

Удаление только выбранных image IDs через Docker не удаляет эти host paths
или volumes. Перед фактическим удалением необходимо повторно получить
список всех контейнеров и убедиться, что ни один не ссылается на кандидатов.
На финальной проверке все три кандидата всё ещё существуют и не связаны
с контейнерами; работающий backend healthy, revision `c9cf1874`, restart count 0.
Подготовленная команда **не выполнялась**, `--force` не использовать:

```bash
docker image rm \
  sha256:851d3714e61a3f2df22f1bba12d9fe1ce5974b04763dbd708a1275304fa551d1 \
  sha256:c96d121087eb6fc5f6475a3bc2e28d448242a4c87e6637d4e11d176e3f1f4429 \
  sha256:f39b708c6851ca8cf3af7c3f3ba5bde0f1b9c64dfb88bf6a71ecf30d78108549
```

Сохранить:

- Работающий `banano-kling-bot:local`, ID `c902a6b62912`, revision `c9cf1874`.
- Оба явно сохранённых recovery-образа:
  `banano-kling-bot:fix-c221dd2` и
  `banano-kling-bot:rollback-before-c221dd2`.
- Все образы с running/exited/created контейнером; остановленный контейнер
  тоже считается ссылкой. В частности, один untagged Redis-образ используется
  остановленным контейнером другого проекта.
- Образы KSU, neuronuch/neironych, auroom, aicrm, shared base images, volumes
  и любые media/backup directories: вне этого списка удаления. Значительная
  часть общего reclaimable относится к другим проектам, включая 25
  neuronuch-staging образов.

Глобальные `docker system prune -a --volumes`, container/volume prune и
ручное удаление `/var/snap/docker/common/var-lib-docker` не являются планом
этого аудита.
